# Golgappe-Date
❤️ GolGappe Date is a fun, desi-inspired couples game where you guess your girlfriend's favourite golgappe paani flavours across 10 rounds! 🥣✨ Score points for correct guesses and unlock cute romantic challenges for wrong answers. Built with love using vibe coding, featuring playful animations, sound effects, and a mobile-friendly experience. 💕📱
